# FlickerTron · visual Pauper primer

Live: https://naiikaa.github.io/FlickerTron/

An animated primer for the Pauper deck FlickerTron (Ephemerate / Teachings Tron), built from the pilot's own list: [“Teachings Tron” by hannnes23 on Moxfield](https://moxfield.com/decks/M8o2H-CwzkGl7EKcMV7A3A). Strategy notes are adapted from the [PauperBrews guide](https://www.pauperbrews.com/2025/06/flicker-tron-pauper-deck-guide.html), which plays a different 75.

- Tron mana calculator (Mine, Power Plant, one to three Towers)
- Finding Tron, colour filters and splash map
- Sample-hand simulator with London mulligans and the guide's keep rule
- Seven lines played out card by card, including the owner's infinite (three Towers, two Mnemonic Walls, Weather the Storm, Unwind, Ghostly Flicker, Energy Refractor)
- Card roles, the diff against the PauperBrews list, a derived sideboard guide and the full 75

Static site: `index.html` plus `assets/` (`data.js` card data, `lines.js` scenes, `app.js` logic). No build step; it works opened from disk or from any static host.

Card images, rules text and mana symbols come from [Scryfall](https://scryfall.com). Magic: The Gathering is © Wizards of the Coast; this is unofficial fan content. Lettering: [osifont](https://github.com/hikikomori82/osifont) (LGPL-3 with font exception) and Archivo (OFL).
